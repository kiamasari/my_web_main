# SPOT — страница кейса

Кейс «Айдентика и мерч BMX-академии Кости Андреева» для портфолио **by.nanava**.

**Стек:** Next.js 16 (App Router, Turbopack) · React 19 · TypeScript · Tailwind CSS 4. Библиотек для анимаций нет, вся анимация на своём лёгком JS (scroll + `requestAnimationFrame`).

Страница по адресу: **`/work/spot`**

---

## 1. Запуск за 3 минуты

Нужен **Node.js 20.9 или новее**. Проверить версию: `node -v`. Скачать: <https://nodejs.org> (LTS).

```bash
# 1. распакуй архив и зайди в папку
cd spot-case

# 2. установи зависимости (один раз)
npm install

# 3. запусти dev-сервер
npm run dev
```

Открой в браузере <http://localhost:3000/work/spot>.

Другие команды:

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с горячей перезагрузкой |
| `npm run build` | продакшн-сборка (проверяет типы) |
| `npm run start` | запуск собранной версии на :3000 |
| `npm run lint` | проверка TypeScript |

### Картинки — просто положи файлы

Все изображения ищутся в папке **`public/work/spot/`** по имени. Расширение может быть любым: `.webp .avif .jpg .png .gif .svg`, а для видео `.mp4 .webm`. Если файла нет, на его месте стоит заглушка, и в ней написан путь, куда класть файл.

| Файл | Блок | Пропорции |
|---|---|---|
| `hero` | обложка (уже лежит `hero.jpg`) | 16:9 |
| `tasks-flatlay` | Задачи: флэтлей носителей | 1:1 |
| `logo-aka` | Логотип на доске с направляющими (PNG без фона) | 8:3 |
| `character` | Персонаж | 1:1 |
| `style-halftone` | Цвет и графика: полутоновое фото | 16:9 |
| `longsleeve-back` | Лонгслив: спина (основная) | 16:10 |
| `longsleeve-front` | Лонгслив: перед (летающая карточка) | 4:5 |
| `longsleeve-seam` | Лонгслив: деталь у шва (летающая карточка) | 1:1 |
| `gloves-pair` | Перчатки: пара | 16:9 |
| `gloves-palm` | Перчатки: ладонь | 4:5 |
| `gloves-back` | Перчатки: тыльная сторона | 4:5 |
| `poster-1` … `poster-3` | Постеры (лента) | 2:3 |
| `photo-1` | Фотостиль: широкий кадр | 16:9 |
| `photo-2`, `photo-3` | Фотостиль: пара | 4:5 |
| `system` | Одна система: носители | 16:10 |

Советы:
- **Формат:** `.webp`, ширина 2000–2400 px. Next.js сам сожмёт картинку и отдаст нужный размер под экран.
- **Пропорции:** если у картинки другие пропорции, поменяй поле `ratio` у этого блока в `spot.ts`. Например, `"4/3"`.
- После того как добавил файлы: в `npm run dev` достаточно обновить страницу, для продакшна пересобери проект (`npm run build`). На Vercel пересборка происходит автоматически при пуше.

### Убрать блок (например, постеры)

Открой `src/content/cases/spot.ts` и удали из массива `sections` объект с `id: "posters"`. Остальные блоки от него не зависят, аккордеон перестроится сам. Если нужно, убери и тег `"Постеры"` из `tags`.

### Добавить блок

Скопируй любой объект в `sections` и поменяй `id`, `label`, `title`, `text`. В поле `media.kind` выбери раскладку:

| `kind` | Как выглядит |
|---|---|
| `single` | одна большая картинка |
| `grid` | широкая сверху + две снизу |
| `reel` | горизонтальная лента, вылезает за правый край, листается мышью, свайпом и стрелками |
| `overlay` | основная картинка + две «летающие» карточки с параллаксом |
| `construction` | доска с направляющими (для логотипа) + картинка под ней |
| `palette` | плашки цветов + шрифтовая пара + картинка |

HEX-цвета в тексте (`#178EC6`) автоматически превращаются в чипы с кружком цвета.

### Контакты и ссылки (сейчас там заглушки)

Файл `src/content/site.ts`: ссылки на Telegram и Behance, PDF (сам файл положи в `public/portfolio.pdf`), почта, город, адрес сайта.
Соседние кейсы задаются в конце `spot.ts`, в полях `prev` и `next`.

### Цвета кейса

Блок `theme` в `spot.ts`: фон, акцент, цвета «волн» в hero и в футере. Каждый кейс может иметь свою палитру, шаблон страницы при этом не меняется.

### Шрифты

На референсе четыре шрифта:
- **Onest** и **Shantell Sans** бесплатные, они уже подключены через npm (`@fontsource`) и работают офлайн;
- **seasonSans** и **comico** коммерческие. Если купишь лицензию, положи файлы в `public/fonts/` (`season-sans.woff2`, `comico.woff2`) и раскомментируй блок `@font-face` в начале `src/app/globals.css`. Они встанут первыми в стеке шрифтов.

## 3. GitHub

В архиве уже есть git-репозиторий с первым коммитом (ветка `main`).

**Вариант А: через GitHub CLI** (одна команда; нужен `gh`, установленный и авторизованный через `gh auth login`):

```bash
cd spot-case
gh repo create spot-case --public --source=. --remote=origin --push
```

**Вариант Б: через сайт:**
1. На github.com нажми **New repository**, назови его `spot-case`. README не добавляй, репозиторий должен быть пустым.
2. В терминале:
```bash
cd spot-case
git remote add origin https://github.com/<твой-логин>/spot-case.git
git push -u origin main
```

## 4. Деплой на Vercel

1. Зайди на <https://vercel.com/new>, нажми **Import Git Repository** и выбери `spot-case`.
2. Ничего не меняй: Vercel сам определит Next.js. Нажми **Deploy**.
3. Через минуту страница будет доступна по адресу `https://<проект>.vercel.app/work/spot`.

Каждый следующий `git push` будет обновлять сайт автоматически.

## 5. Перенос в основной сайт (by-nanava)

Если основной сайт тоже на Next.js (App Router):
1. Скопируй `src/components/`, `src/content/` и `src/lib/` в его проект.
2. Скопируй `src/app/work/spot/page.tsx` в `app/work/spot/page.tsx`.
3. Добавь стили из `src/app/globals.css` в его глобальные стили, установи шрифты: `npm i @fontsource-variable/onest @fontsource/shantell-sans` (импорты смотри в `src/app/layout.tsx`).
4. Скопируй `public/work/spot/`.
5. В `site.ts` поправь `allCasesHref` на якорь списка проектов основного сайта.

## Что улучшено относительно референса

- **Один конфиг вместо дублирования.** Тексты пишутся один раз в `spot.ts`. На десктопе они показываются в аккордеоне, на мобилке в карточках над медиа.
- **Картинки без правки кода.** Достаточно положить файл с нужным именем, вместо отсутствующих стоят подписанные заглушки.
- **Прогресс-полоска** в активном пункте аккордеона; клик по пункту плавно прокручивает к секции и обновляет `#якорь` в адресе.
- **Лента постеров** листается перетаскиванием мышью, свайпом и кнопками-стрелками, со снапом к карточкам.
- **Параллакс** у «летающих» карточек мерча.
- **ASCII-логотип в футере.** Вращающаяся 3D-надпись `by.nanava` подстраивается под ширину экрана и ставится на паузу, когда её не видно.
- **Плавающая панель** прячется, когда виден футер, чтобы не перекрывать контакты.
- **На вертикальных экранах** обложка hero не обрезается.
- **Доступность:** поддержка `prefers-reduced-motion` (анимации отключаются, hero становится статичным), видимый фокус для клавиатуры, aria-разметка, alt-тексты.
- **SEO:** title, description, canonical, Open Graph и Twitter-карточка с обложкой.
- **Тема на CSS-переменных:** новый кейс со своей палитрой собирается без правки стилей.
